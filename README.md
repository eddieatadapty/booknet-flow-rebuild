# Booknet Growth Audit

**Live → https://eddieatadapty.github.io/booknet-flow-rebuild/**

Five ideas to turn more Booknet users into subscribers, each built into a clickable version of Booknet's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open the book from the ad, not the library | +10–20% book purchases |
| 02 | Read first, sign in after the purchase | +5–10% book purchases · ARPU +10–17% |
| 03 | Sell the book where the free chapters end | +10–15% book purchases |
| 04 | Make the top-up cover the book | +5–15% book purchases · ARPU +5–10% |
| 05 | Keep the readers who close it | +5–10% ARPU |

Every price, rating and feature comes from Booknet's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Booknet. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
